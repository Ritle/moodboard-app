# JSON-документ MoodBoard

Текущая версия схемы — `2`. Документ является единственным сохраняемым описанием листов и их холстов; состояние интерфейса, активный лист, viewport, selection, undo/redo и объекты Konva в него не входят.

## Корневая структура

```json
{
  "schemaVersion": 2,
  "pages": [
    {
      "id": "page-id",
      "name": "Лист 1",
      "canvas": {
        "width": 1600,
        "height": 1000,
        "background": "#ffffff"
      },
      "elements": []
    }
  ]
}
```

- `schemaVersion` — целое число, для этой версии строго `2`;
- `pages` — непустой массив листов;
- `pages[].id` — непустой уникальный ID листа;
- `pages[].name` — название длиной 1–80 символов;
- `pages[].canvas.width`, `pages[].canvas.height` — положительные конечные числа;
- `pages[].canvas.background` — непустая CSS-строка цвета;
- `pages[].elements` — элементы в порядке слоёв: первый находится сзади, последний спереди.

Активный лист выбирается в `EditorStore.uiState.activePageId`. Создание, копирование, переименование и удаление меняют массив `pages` и сохраняются обычным autosave. В документе всегда остаётся минимум один лист.

## Общие поля элемента

| Поле | Тип | Назначение |
|---|---|---|
| `id` | string | Непустой уникальный ID внутри документа |
| `type` | string | `image`, `text`, `shape`, `brush`, `highlighter`, `sticker`, `arrow` или `frame`; `rectangle` читается как legacy-тип |
| `name` | string | Необязательное имя слоя для карты слоёв, 1–80 символов; для `frame` обязательно |
| `x`, `y` | number | Координаты в системе виртуального холста |
| `width`, `height` | number | Положительные размеры |
| `rotation` | number | Поворот в градусах |
| `opacity` | number | Прозрачность от `0` до `1` |
| `locked` | boolean | Необязательный признак блокировки перемещения, трансформации и изменения свойств |
| `hyperlink` | string \| null | Необязательный внешний URL `http://` или `https://`, не длиннее 2048 символов |
| `frameId` | string | Необязательная ссылка на `frame` того же листа; у самого фрейма отсутствует |
| `clipContent` | boolean | Только для `frame`: обрезать вложенные объекты по границам; отсутствие равно `true` |
| `backgroundColor` | string | Только для `frame`: цвет фона в HEX; по умолчанию `#ffffff` |
| `backgroundOpacity` | number | Только для `frame`: прозрачность фона от 0 до 1; отсутствие или `0` означает фон без заливки |
| `layoutGridColumns` | integer | Только для `frame`: 0–12 колонок, `0` отключает сетку |
| `layoutGridGap` | number | Только для `frame`: промежуток между колонками, 0–200 px |
| `layoutGridPadding` | number | Только для `frame`: внутренний отступ сетки, 0–200 px |
| `groupId` | string | Необязательный непустой ID постоянной группы элементов внутри листа |
| `groupName` | string | Необязательное общее имя постоянной группы, 1–80 символов; записывается во всех участников |
| `groupPath` | string[] | Необязательный путь вложенности от внешней группы к внутренней, до 12 уникальных ID; первый ID совпадает с `groupId` |
| `groupNames` | object | Необязательное соответствие ID групп из `groupPath` их именам длиной 1–80 символов |

Координаты, поворот, прозрачность, `locked`, `name` и поля групп могут отсутствовать в старой записи — renderer применит значения по умолчанию; исключением остаётся обязательное `name` фрейма. Отсутствие `locked` эквивалентно `false`. Для совместимости одиночный `groupId` читается как `groupPath: [groupId]`. Элементы с одинаковым внешним `groupId` выбираются как единое целое на холсте; карта слоёв позволяет обращаться к вложенным группам. При копировании переназначаются все ID из `groupPath`, поэтому копия не объединяется с оригиналом. Разгруппировка удаляет только выбранный уровень и сохраняет дочерние группы.

## Изображение

```json
{
  "id": "image-42",
  "type": "image",
  "assetId": "asset-17",
  "x": 120,
  "y": 80,
  "width": 640,
  "height": 426.67,
  "aspectRatio": 1.5,
  "flipX": false,
  "flipY": false,
  "cornerRadius": 24,
  "backgroundRemoved": true,
  "eraseMask": {
    "version": 1,
    "strokes": [
      { "size": 0.08, "points": [0.24, 0.31, 0.27, 0.34] }
    ]
  },
  "hyperlink": "https://example.com/product/17",
  "rotation": 0,
  "opacity": 1
}
```

`assetId` обязателен и ссылается на Blob в repository. Сам Blob и object URL в JSON не входят. `aspectRatio` используется для пропорционального resize; `flipX` и `flipY` отвечают за отражение без сохранения технических Konva scale. Необязательный `cornerRadius` задаёт скругление углов изображения в пикселях сцены от `0` до `1000`. Поле продолжает валидироваться и отрисовываться для совместимости с ранее созданными и импортированными документами, но отдельный контрол скругления в текущем toolbar скрыт. Необязательный boolean `backgroundRemoved` отмечает, что ИИ-удаление фона уже применялось к изображению, и запрещает повторную отправку в сервис.

Необязательный `eraseMask` хранит неразрушающее ручное удаление фона отдельно для каждого экземпляра изображения. `points` содержит пары координат от 0 до 1 относительно изображения, `size` — диаметр ластика относительно ширины изображения. Версия маски равна `1`; допускается не более 500 штрихов, 50 000 точек суммарно и 2 000 точек в одном штрихе. Исходный Blob не изменяется. При замене изображения маска удаляется, при ИИ-обработке существующая маска применяется поверх нового результата. Отсутствующий asset не делает документ невалидным: редактор показывает error-placeholder и уведомление.

## Текст

```json
{
  "id": "text-8",
  "type": "text",
  "text": "Материалы и фактуры",
  "x": 96,
  "y": 72,
  "width": 520,
  "height": 120,
  "rotation": 0,
  "opacity": 1,
  "fill": "#282828",
  "fontFamily": "Roboto",
  "fontSize": 48,
  "fontStyle": "normal",
  "align": "left"
}
```

`text` обязателен и может быть пустой строкой. Поддерживаемые интерфейсом значения `fontStyle`: `normal`, `bold`; `align`: `left`, `center`, `right`. Toolbar предлагает пресеты Basic (`Roboto`), Modern (`Inter`), Classic (`Georgia`), Draw (`Comic Sans MS`) и Technical (`Roboto Condensed`).

## Фигура

```json
{
  "id": "shape-3",
  "type": "shape",
  "shapeType": "rectangle",
  "x": 260,
  "y": 180,
  "width": 360,
  "height": 240,
  "rotation": 0,
  "opacity": 1,
  "fill": "#8094b1",
  "stroke": "#707070",
  "strokeWidth": 3,
  "hyperlink": "https://example.com/catalog/item",
  "cornerRadius": 16
}
```

`shapeType` принимает `rectangle`, `circle`, `diamond`, `triangle`, `star`, `oval`, `hexagon`, `cloud`, `arrow-left`, `arrow-up`, `arrow-down`, `arrow-right`, `checkbox-x` или `checkbox-v`. `strokeWidth` использует значения 0 (None), 1 (Thin), 3 (Medium) и 6 (Thick). Legacy-элемент с `type: "rectangle"` читается как прямоугольник и нормализуется в `type: "shape"` при следующем изменении его свойств.

## Штрих кисти

```json
{
  "id": "brush-4",
  "type": "brush",
  "x": 320,
  "y": 240,
  "width": 280,
  "height": 120,
  "rotation": 0,
  "opacity": 1,
  "points": [0.01, 0.48, 0.18, 0.22, 0.43, 0.67, 0.99, 0.51],
  "stroke": "#282828",
  "strokeWidth": 5
}
```

`points` содержит пары нормализованных координат `x, y` в диапазоне от 0 до 1 относительно прямоугольника объекта. Допустимые значения `strokeWidth` интерфейса кисти: 2 (Thin), 5 (Medium), 10 (Thick), 18 (Extra thick).

## Выделитель

```json
{
  "id": "highlighter-5",
  "type": "highlighter",
  "x": 180,
  "y": 320,
  "width": 540,
  "height": 74,
  "rotation": 0,
  "opacity": 0.35,
  "points": [0.01, 0.52, 0.3, 0.45, 0.68, 0.56, 0.99, 0.48],
  "stroke": "#ffdf5d",
  "strokeWidth": 40
}
```

`highlighter` хранится как векторный штрих с той же нормализацией `points`, что и кисть. Интерфейс предлагает толщины 16, 28, 40 и 56 и прозрачность 0.15, 0.25, 0.35 или 0.5.

## Текстовый стикер

```json
{
  "id": "sticker-6",
  "type": "sticker",
  "x": 740,
  "y": 180,
  "width": 300,
  "height": 260,
  "rotation": 0,
  "opacity": 1,
  "text": "Согласовать палитру материалов",
  "fill": "#ffdf6b",
  "textColor": "#282828",
  "fontFamily": "Roboto",
  "fontSize": 28,
  "fontStyle": "normal",
  "align": "left",
  "strokeWidth": 1,
  "hyperlink": "https://example.com/materials"
}
```

Для `sticker` обязательны строка `text` и HEX-цвета `fill`/`textColor`. `hyperlink` необязателен и проходит общую проверку HTTP(S)-адресов.

## Фрейм

```json
{
  "id": "frame-7",
  "type": "frame",
  "name": "Материалы кухни",
  "x": 140,
  "y": 120,
  "width": 720,
  "height": 480,
  "rotation": 0,
  "opacity": 1,
  "stroke": "#3183ff",
  "backgroundColor": "#ffffff",
  "backgroundOpacity": 0.5,
  "clipContent": true,
  "layoutGridColumns": 4,
  "layoutGridGap": 16,
  "layoutGridPadding": 16,
  "locked": false
}
```

Фреймы не вкладываются друг в друга. Привязанный обычный элемент хранит `frameId: "frame-7"`; валидатор требует, чтобы такой фрейм существовал на том же листе. Порядок слоёв хранит фрейм перед его содержимым. При перемещении контейнера координаты фрейма и всех привязанных объектов изменяются одной командой. При переносе центра вложенного объекта в другой фрейм его `frameId` обновляется автоматически; перенос поддерживает undo/redo.

`clipContent` включает визуальную обрезку содержимого по повёрнутому контуру фрейма и по умолчанию считается `true`, в том числе для старых документов без этого поля. `backgroundColor` и `backgroundOpacity` задают заливку контейнера под его содержимым; старые фреймы без этих полей остаются прозрачными. Фон попадает в preview, PNG и PDF. `layoutGridColumns` задаёт число колонок сетки компоновки: `0` отключает сетку, UI предлагает 2, 3, 4, 6 и 12 колонок. `layoutGridGap` и `layoutGridPadding` задают промежуток и внутренний отступ в пикселях. Сетка служит направляющей редактора и не попадает в preview, PNG или PDF.

## Стрелка / линия

```json
{
  "id": "arrow-8",
  "type": "arrow",
  "x": 240,
  "y": 180,
  "width": 520,
  "height": 190,
  "rotation": 0,
  "opacity": 1,
  "points": [0, 0.5, 0.48, 0, 1, 0.72],
  "stroke": "#282828",
  "strokeWidth": 5,
  "startCap": "none",
  "endCap": "arrow1",
  "bindings": {
    "start": {
      "targetElementId": "shape-3",
      "anchor": { "x": 1, "y": 0.5 }
    }
  }
}
```

`points` всегда содержит три пары нормализованных координат: начало, управляющую точку квадратичной кривой и конец. `strokeWidth` в интерфейсе принимает 2, 5, 10 или 18. Поля `startCap` и `endCap` настраиваются независимо и принимают `none`, `arrow1` (заполненная стрелка) или `arrow2` (контурная стрелка). При редактировании точек bounding box и нормализованные координаты пересчитываются, поэтому документ не хранит служебные transform-свойства Konva.

Необязательный объект `bindings` хранит привязки `start` и `end` к объектам того же листа. `targetElementId` может ссылаться на изображение, текст, фигуру, стикер или фрейм. Координаты `anchor.x` и `anchor.y` нормализованы относительно локального прямоугольника цели и находятся в диапазоне от 0 до 1. При перемещении, изменении размера или повороте цели координаты стрелки обновляются в той же операции истории.

## Инварианты и совместимость

- ID листов и элементов не повторяются в пределах документа.
- `width` и `height` больше нуля; числовые поля не содержат `NaN` или `Infinity`.
- Для `image` обязателен непустой `assetId`.
- `image.eraseMask`, если указан, должен соответствовать версии 1 и содержать только конечные нормализованные координаты.
- `flipX`/`flipY` и `image.backgroundRemoved` являются boolean, `image.cornerRadius` — числом от 0 до 1000, `strokeWidth` — неотрицательным числом, `hyperlink` — допустимым HTTP(S)-адресом.
- Технические свойства Konva (`scaleX`, `scaleY`, `draggable`, `className`, `_id`) запрещены.
- Неизвестная `schemaVersion` должна отклоняться до открытия редактора.
- Документ schemaVersion 1 с корневыми `canvas` и `elements` автоматически преобразуется в schemaVersion 2 с одним листом «Лист 1».
- Миграции выполняются на границе repository/model и завершаются до передачи документа в `EditorStore`.

Каноническая валидация реализована в `assets/js/models/moodboard-document.js`.
